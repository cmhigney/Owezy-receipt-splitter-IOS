Firebase deploy commands

C:\Users\cmhig\Downloads\Owezy-Bill-Splitter-IOS-ANDROID-main\Owezy-Bill-Splitter-IOS-ANDROID-main

PowerShell commands:

cmd /c "npm --prefix functions install"

firebase deploy --only "functions,firestore"

Why this command:
- PowerShell requires quotes around `functions,firestore` or it splits the targets incorrectly.
- `cmd /c npm ...` avoids the local PowerShell script execution-policy issue on this machine.
